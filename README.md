# python-library-management
A simple console-based library management system written in Python.

Features

- Add, view, search, edit, and delete books
- Add and view members
- Borrow and return books
- View loan records
- Save data in a JSON file

Technologies

- Python
- JSON

Requirements

Python 3

How to Run

1. Download or clone this repository.
2. Open a terminal in the project folder.
3. Run the following command:

python main.py

If your system uses "python3", run:

python3 main.py
